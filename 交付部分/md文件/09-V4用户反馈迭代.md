## 三、迭代实施（v6.39 + v6.40）

### v6.39（反馈 #1，gh-pages `067a64d`）
- 亮点区块从页尾前置到标题卡下方；长文新增分节目录条（点击平滑滚动 + 滚动高亮当前节）。

### v6.40（反馈 #2-#6，gh-pages `e9f1d12`）

## 五、过程中的三次翻车与修复（已完整记录进《AI协作日志》案例 M）

1. **文档批量替换污染**：非唯一锚点把反馈记录表 7 行误替换，且 python 失败未阻断 git 推送——从 git 历史恢复整份文档重写，锚点唯一性 + 落盘校验 + `&&` 阻断改为硬规则。
2. **timeout 误诊**：macOS 无 `timeout` 命令，探测脚本自身报错被当成"网络故障"白等 20 分钟——教训：探测手段失效时应先验证探测手段。
3. **反馈数量对不上**：用户称传了很多反馈、实际只收到 1 条——如实说明并请补发，不编造输入。用户补发后（5 张截图）才继续处理。
