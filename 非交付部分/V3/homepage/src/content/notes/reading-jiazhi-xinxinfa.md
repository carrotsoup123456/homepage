# 《价值心法》：自身就可以成为一个公司 1.0

> **摘要**：这是我的思想启蒙书。它让我第一次意识到：一个人可以像经营公司一样经营自己。读完我给自己设计了一整套"公司架构"——五个系统（反思、自学、计划、判断、收集）、七条指导思想（IPO、第一性原理、二八法则……）、五个日常模块（睡眠、单词、复习、阅读、运动），并用两次真实的"学费事件"做了第一轮反思复盘。后面读的纳瓦尔、芒格、阿德勒，都是在给这套系统打补丁。

## 一、系统

### 反思系统（5 步）

1. 观想法
2. 重新识别、推导
3. 寻找已有的、可借鉴的解决方法
4. 找对比，反思重构
5. 利用计划系统重新试验，获得反馈

### 自学系统

**课内（6 步）**：预习找问题 → 上课抓推导 → 当天整理 → 利用计划系统排复习 → 练习书输出验证 → 错题进反思系统。

**课外（7 步）**：以问题为入口 → 找材料（书/课/AI）→ 利用计划系统切时间 → 输出（讲课录音、写笔记）→ 用判断系统审视 → 进提取/收集系统 → 定期回炉。

### 计划系统（7 步）

1. 明确目标
2. 列举方法
3. 用剃刀原则和 KISS 原则保留主要部分（如无必要，勿增实体；Keep it simple, stupid）
4. 二八法则挑出最关键的 20%
5. 划分时间
6. 运行
7. 定期用反思系统自查、调整

### 判断系统

先不做出任何评价，保持静默 → 识别对方的观点与理由 → 思考三个方面的问题 → 不断追问 → 分支：经得起推敲 / 经不起推敲 → 得出暂时评价 → 定期反思、重新推敲。

### 提取 / 收集系统

分「思维」「idea」两栏，随时存，定期回看喂给反思系统。

## 二、指导思想（7 条）

| 原则 | 一句话 |
| --- | --- |
| IPO | Input → Process → Output，一切学习都是流水线 |
| KISS + 剃刀 | 如无必要，勿增实体 |
| B=MAP | 行为 = 动机 × 能力 × 提示 |
| PDCA | 计划-执行-检查-处理循环 |
| OODA | 观察-定向-决策-行动循环 |
| 第一性原理 | 回到事实与公理重新推导 |
| 二八法则 | 20% 的投入决定 80% 的产出 |

## 三、模块（时间表）

| 模块 | 规则 |
| --- | --- |
| 睡觉 | 10:50 睡，6:20 起；10:30 后禁止使用电子设备 |
| 背单词 | 每日 30 分钟（6:40–7:10） |
| 饭澡 | 50 分钟（吃饭 15min、洗澡 35min） |
| 复习 | 每日 21:40 复习昨日知识点与错题；每周日晚第二节晚修复习本周错题 |
| 阅读运动 | 每日读满 20min 书；每日至少 15min 运动 |

## 四、反思记录（学费单）

**事件 ①：高二上数学建模大赛（2024.11.4）**
学费：花了大量时间，几乎 80% 都是自己写的。
反思：**要学会利用 AI（杠杆）的力量。**

**事件 ②：纪中校庆 90 周年宣传片拍摄（2024.10.19 / 11.3）**
学费：浪费了大量时间精力，最后没有特写（即仅为群演）。
反思：**要学会去争取自己的机会，无论结果如何。**
