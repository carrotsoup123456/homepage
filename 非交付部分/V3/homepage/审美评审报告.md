## 0. Design Read（一句话定性）

> 个人作品集主页（求职 + 课程作业双用途），面向招聘者与课程评审，走「森林 / 画廊」自然艺术语言，偏原生 CSS + 自定义设计令牌 + 大量手绘 SVG 与装饰动效。设计基调与主流 AI 默认审美（紫渐变 + 居中 Hero + 三张等宽卡片）刻意拉开了距离，这点做对了。

## 1. 已经做得好的部分（认可，保持）

### 1.1 设计令牌体系规范
- `--color-*` 系列命名清晰，浅色（暖米白 `#f2ede2`）与深色（森林夜 `#0e120d`）两套完整对偶，每个值都带注释说明用途甚至对比度（如 `--color-green` 标注 4.55:1）。
- 间距、圆角、阴影、缓动、字体统一走 `--radius` / `--shadow` / `--ease` / `--font-*`，没有散落的魔法数字。

### 1.2 色彩不落 AI 默认俗套
- 主色是**石板蓝 `#3c5468`** + **生机绿 `#3e774e`** 的「森林 / 画廊」气质，不是 AI 紫 / 蓝发光。中性底色是暖米白而非 slate-900 + Inter。这在同类课程作业里是显著差异化。

### 1.3 无障碍处理全面（这是真功夫）
- `prefers-reduced-motion` 覆盖了几乎所有动效（萤火虫、marquee、bgm-sway、视差、开场动画等）。
- skip-link、`:focus-visible`、`aria-current` / `aria-expanded` / `aria-live`、逐页 title / og / canonical、`img width/height` 防 CLS。
- 图片灯箱有完整的键盘闭环：Esc 关闭、焦点还给触发图、`role="dialog" aria-modal`。
- 移动端有专门设计：两行三列按钮网格、`v-reveal` 手机端直显（历史反馈驱动的改进）。

### 1.4 个性化基因扎实
- 胡萝卜坑页脚、种子彩蛋、数字分身、全站圆舞曲、云层开场——这些是「你是谁」的签名，是加分项不是减分项。

## 2. 需要严肃指出的设计 / 工程问题

### 2.1 🔴 P0（必修）设计令牌不一致，直接破坏两个页面

`src/style.css` 的 `:root` 只定义了 `--color-*`、`--accent-soft`、`--wave-color` 等。但音乐页、知识库分栏、页头 BGM 按钮在引用**另一套从未定义过的令牌**：

| 未定义变量 | 引用位置（无 fallback） | 后果 |
|---|---|---|
| `--line` | `MusicView.vue` `.bgm-card` / `.p-btn` / `.p-progress`；`style.css` `.kb-cat` / `.bgm-toggle` | `border: 1.5px solid var(--line)` 整条声明失效 → 边框消失 |
| `--panel` | `.bgm-card` / `.kb-cat` / `.kb-reading-intro` / `.bgm-toggle` | `background` 失效 → 卡片背景透明 |
| `--ink` / `--ink-soft` | `.bgm-title` / `.bgm-note` / `.p-btn` / `.kb-cat` 等 | `color` 失效 → 文字回退继承色 |
| `--accent` | `.p-main`（主播放按钮）/ `.p-progress-fill` / `.kb-cat.active` | **背景失效**，主按钮透明底 + 白字，几乎不可见 |
| `--bg` | `.p-btn` | 背景失效 |

全项目搜证：这套 `--accent` / `--ink` / `--ink-soft` / `--line` / `--panel` / `--bg` 的**唯一定义在 `game-src/weiguan-yifang.html:9`**——那是一个独立的游戏 HTML，不进 Vue 打包。

**影响范围**：音乐页整页（BGM 卡片、播放/音量按钮、进度条）、知识库的分栏切换按钮、页头圆形 BGM 开关——视觉全部退化。

**修复方向（供参考，未动手）**：要么在 `style.css` 的 `:root` / `[data-theme]` 里补定义这套别名（如 `--accent: var(--color-primary)`、`--ink: var(--color-text)`、`--ink-soft: var(--color-text-muted)`、`--line: var(--color-border)`、`--panel: var(--color-surface)`、`--bg: var(--color-bg)`）；要么把引用处统一点改成 `--color-*` 系列。前者改动最小。

> 附带说明：`--carrot`（胡萝卜橙 `#e8842c`）有 fallback `var(--carrot, #e8842c)`，不会坏，只是没进令牌体系、是散落的一处点缀色。

### 2.2 🟠 P1（建议修）AI 蓝残留，破坏色彩一致性锁定

两处还残留早期 Tailwind blue-600 时代的颜色，与主色石板蓝 `#3c5468` 不符：

- `SiteFooter.vue:221` 返回顶部按钮阴影 `rgba(37, 99, 235, 0.3)`
- `ProjectDetailView.vue:242` 项目 tech 标签背景 `rgba(37, 99, 235, 0.1)`

taste-skill 的「色彩一致性锁定」：一页只能有一个强调色。这两处是漏网之鱼。

### 2.3 🟠 P1 eyebrow 文案重复

- 「Beyond Code」用了两次：`HomeView.vue:364`（阅读板块）、`:434`（经历板块）
- 「Selected Work」用了两次：`HomeView.vue:382`（项目）+ `AboutView.vue:146`

eyebrow 是板块的「眉标」，重复会让页面显得词汇量不够、两块内容的定位模糊。建议其中一个换词（如「Reading」「Experience」各自独立成词）。

### 2.4 🟠 P1 两套图标语言并存，风格割裂

- 页头导航是**手绘 1.8px 圆头 SVG**（`icons` 对象，统一 stroke、统一气质）。
- 但数据层 `site.js` 的项目 icon 是 emoji（🥕🧠📈🏯📌）、联系方式是 emoji（📧📞）、项目详情页按钮和表单状态用 emoji（👤🏯🔗✅⚠️），反馈组件用 👍🤔。

手绘线稿和彩色 emoji 是两种完全不同的图形语言，放在同一站里会显得细节不一致。要么全部手绘 SVG（气质最统一），要么接受 emoji 但要明确哪些场景用哪种（taste-skill 允许「有文档规则」的混合，但现在没有规则）。

## 3. 个性化设计的改进建议（不是否定，是打磨）

| 个性化设计 | 现状评价 | 改进建议 |
|---|---|---|
| 胡萝卜坑页脚 SVG 彩蛋 | 可爱、是签名 | 已经 `aria-hidden`，做得好。建议给「胡萝卜」加一句 `title` 或注释提示是彩蛋，否则访客可能没发现 |
| 种子彩蛋（hill-band） | 有记忆点 | 发现方式偏隐晦；建议首次进入时给一个极轻的提示（不打断） |
| 数字分身 ChatBot | 检索式匹配，本机完成，够用 | 建议限定出现时机（滚动到某处再弹、或首次访问才自动开），避免每次进站都抢占注意力 |
| 全站圆舞曲 BGM | 有断流自愈 + 80kbps 压缩，工程考虑到位 | 已守「用户手势才出声」底线，很好；建议记住用户的静音选择（localStorage） |
| SiteIntro 云层开场动画 | 氛围好，是亮点 | 建议加「记住已看过」跳过，重复访问者每次都要穿云会烦 |
| PixelWave 全屏点击涟漪 canvas | 有氛围 | 全屏 canvas 有性能成本，建议移动端降级或限制涟漪数量 |

## 5. 一句话总结

设计底子很好——令牌体系规范、色彩不落俗套、无障碍处理是同类作品里少见的完整，个性化签名也有真东西。**当前最要紧的是一处设计令牌没接上的工程 bug（P0），它让音乐页和知识库分栏的视觉直接退化**；其余是色彩残留、文案重复、图标语言割裂这些「一致性」层面的打磨，优先级次之但顺手就能修。
