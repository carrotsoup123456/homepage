## 六、⚠️ 侵权规避指南（务必看）

「参考灵感」和「抄袭侵权」的界线在于：**思想/模式不受版权保护，具体表达受保护**。

### ✅ 可以做的
- 参考**布局结构、信息层级、交互模式、配色思路**（属于「思想/方法」）。
- 学习**动效原理**后自己重新实现。
- 使用**明确免费商用**的素材（见下）。
- 分析优秀网站「为什么好看」并转化为自己的设计原则。

### ❌ 不要做的
- **直接下载、另存、截图后当自己的作品**提交。
- **1:1 复刻**某个具体网站（配色+排版+图形组合的「整体表达」可能构成侵权）。
- 复制他人的**代码、图片、图标、字体、文案**（除非有明确授权）。
- 使用**带水印**的图片、盗用**商标 / logo**。
- 使用来源不明的**模板 / 主题**（若使用，务必遵守其 License）。

### 🧰 合规素材来源（推荐直接用这些，而不是扒别人的图）

| 类型 | 推荐（多为免费可商用） | 备注 |
|------|----------------------|------|
| 图片 | Unsplash、Pexels、Pixabay | 免费商用，注意个别作者要求署名 |
| 图标 | Lucide、Heroicons、Feather | 开源，注意各自 License（多为 MIT） |
| 字体 | Google Fonts（开源字体）、系统字体 | 商用前确认字体授权 |
| 头像 | 用自己的照片；或 DiceBear 等生成头像 | 你的主页已用真实头像 ✅ |

| 图表 | 自己项目的真实截图 | 你已用真实量化截图 ✅ |

### 📝 课程层面的加分做法（过程可追溯 + AI 合规）
建立一个 **「灵感来源清单」**，记录：看了哪个网站、参考了什么、如何转化为自己的设计。这既规避抄袭嫌疑，又符合课程要求的「引用与署名」。

## 七、给 V3 的方向建议（供你选择）

结合你主页现状（Vue 3 + 简历主页 + 已有深色模式/知识库/联系表单），V3 个性化可以从这些方向里挑 1–2 个：

| 方向 | 参考网站 | 说明 |
|------|----------|------|
| **A. 极简高级感** | Minimal Gallery、Admire the Web | 大量留白 + 精致排版 + 克制动效，显得更专业 |
| **B. 单页沉浸式** | One Page Love、Godly | 一页滚动讲完故事，配合滚动动画 |
| **C. 个人作品集风** | SiteInspire、Land-book | 更突出项目展示，图文更大更清晰 |
| **D. 动效/实验感** | Awwwards、The FWA、Codrops | 加入有质感的微交互与滚动动效（注意别过度） |
| **E. 交互精细化** | Mobbin、Refero | 把现有页面细节（表单、卡片、导航）打磨到位 |

> 建议：**先选定 1 个主方向 + 1 个点缀方向**，避免风格混杂；确定后我可以直接帮你在 V3 里实现。
