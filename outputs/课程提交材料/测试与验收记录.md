**③ 反向验证 —— 这批最有价值的一条经验**

新加的断言必须"挑剔得动"。做法：**故意把被测对象改坏，看断言会不会变红**。

|------|--------------|------|
| 1 | 删掉 `img { height: auto }` | ✅ 变红 |
| 2 | 把兜底路由改回"重定向首页" | ❌ **没变红** |
| 3 | 把图片指向不存在的文件 | ✅ 变红 |

第 2 轮是关键发现：**原断言只检查"路由名是不是 `not-found`"，而一条 `redirect: '/'` 的路由名字也可以叫 `not-found`** —— 页面其实跳走了，测试却给绿灯。

> 顺带说明反向验证的收尾纪律：弄坏的文件一律先用备份还原、跑一遍全绿、确认 `git status` 只剩预期改动，再删备份。

**⑤ 过程中的一次"假警报"（值得记下来）**

线上复验时一度出现**内容不换、始终停在首页**：标题跟着路由变，但 `<h1>` 与正文一直是首页的。看着像严重的线上回归。

查证过程：

| 步骤 | 观察到的现象 |
|------|--------------|
| 1 | 直接用调试协议问页面：`requestAnimationFrame` 在 1 秒内触发了 **0 次** |
| 2 | 同一时刻 `document.visibilityState` 是 **`hidden`**（标签页在后台） |
| 3 | 路由容器的 class 卡在 `page-leave-active`，没进到下一步 |

> 教训：**验证页面状态既不能"打开就开始读"，也不能用固定等待**。要么轮询到状态真正落定，要么先确认当前标签页确实在前台（`visibilityState === 'visible'`）。

**② 根因（三行 CSS 的相互作用）**

工作项是「图标 | 文字块 | 角色标签」横排：文字块 `flex: 1; min-width: 0`（可以被压到 0），角色标签 `flex-shrink: 0`（不许压缩，最长一条实测 366px）。两者相加超过手机宽度 → 内容最小宽度锁在 **459px**（320~414 五档实测一致），标题被挤成 32×331 的竖排。已有的 `flex-wrap: wrap` 救不了——文字块初始宽度为 0，"永远装得下"，浏览器没有换行理由。

## 5.13 图片性能优化 + 推挤式菜单（2026-09-26，main `75f0f5f` / gh-pages `a49f2c4`）

用户真机反馈：照片加载慢、常只加载一半；汉堡菜单展开后「头部栏锁定在顶部、不跟选项栏一起动」。

### 1. 图片优化（WebP + 尺寸收敛 + 预加载）

**做法**：24 张被引用图全部转 WebP 并按「页面显示宽 × dpr2 余量」收敛尺寸；hero 背景图与头像加 preload/fetchpriority（背景图走 CSS 引用，浏览器发现最晚，是 LCP 短板）；删除 3 张未引用冗余图（icon.png 479KB 等）。`gen-image-sizes.mjs` 增加 WebP 文件头解析（VP8/VP8L/VP8X 三种编码）。

**体积对比**（public 下被引用图片合计）：

| | 优化前 | 优化后 | 降幅 |
|---|---|---|---|
| 图片文件体积 | 4821KB | 1318KB | **−73%** |

**线上实测**（CDP 模拟手机 390px + 慢 4G 节流 150ms/1.6Mbps + 冷加载禁缓存）：

| 指标 | 优化后实测 |
|---|---|
| TTFB | 303ms |
| FCP | 1876ms |
| load | 3038ms |
| 首屏传输（含 3 张首屏图） | 498KB / 8 请求 |
| 整页图片（全部 lazy 触发后） | **705KB / 12 张** |

「只加载一半」的直接成因是大图慢 + 渐进式渲染中断；单张图从最大 496KB 降到最大 222KB（hero 背景）后，慢网下的完成率显著改善。

### 2. 推挤式菜单

**用户反馈**：fixed 覆盖式菜单展开后，头部栏像「锁定」在顶部、不跟选项栏一起动。
**改法**：菜单从 `position:fixed` 盖层改为**文档流推挤式**——`.nav` 窄屏允许换行，菜单 `max-height` 过渡展开、独占整行把页面往下推；同时**移除 body 滚动锁**（推挤式不再需要）。

**线上验证（390px）**：开菜单 header 高 75→390px（文档流撑高）✓；菜单 position=static ✓；body overflow=visible（不再锁死）✓；菜单开着时页面可滚（scrollY=300）✓；收起恢复 75px ✓。

### 3. 验证与回归

- `npm test` 61/61 ✓（测试内图片路径同步为 webp）
