## 二、核心亮点（评审看点）

1. **从想法到可运行原型的完整闭环**：V0 规划 → V1 简历主页 → V2 多功能主页 → V3 视觉重设计 → 公网发布，全程有 Git 历史与对话记录留痕。
2. **V2 功能密度高**：多页路由、深色模式、项目详情（Markdown 渲染）、知识库、联系表单、返回顶部、滚动渐入、响应式、图片灯箱。
3. **V3 视觉重设计（当前线上）**：画廊 / 森林夜双主题，衬线大标题、满屏写实森林 Hero + 分层视差、拱形画框人像、技能跑马灯、宣言画框、左右交替特性行；**背景素材为 AI 原创生成**，学习参考作品的设计语言而不复刻其表达（规避侵权）。
   - **5 项动态效果**（纯 CSS + 原生 JS，无新增依赖，遵守 `prefers-reduced-motion`）：首屏进场编排、森林萤火虫粒子、鼠标跟随柔光、统计数字滚动增长、区块交错滑入。
4. **真实可用的联网服务**：联系表单接入 **FormSubmit**，访客留言**真实发送到我的邮箱**（非假提交演示）。
5. **真实的量化项目支撑**：主页展示的「股票量化软件」是我本人的真实项目（LightGBM 策略，回测总收益 112.74%）。
6. **完整的 AI 合规记录**：见 [`AI协作日志.md`](./AI协作日志.md)，含关键 prompt、AI 输出、我的批判性评估与修正。

## 五、技术栈

- **前端框架**：Vue 3（Composition API + `<script setup>`）
- **构建工具**：Vite
- **路由**：Vue Router 4（hash 模式，适配静态托管子路径）
- **Markdown 渲染**：marked
- **样式**：原生 CSS（CSS 变量 + `[data-theme='dark']` 深色覆盖）
- **联系表单后端**：FormSubmit（第三方，无服务器）
- **部署**：GitHub Pages（gh-pages 分支静态托管）
- **开发环境**：Node.js + npm；Cursor / DeepWorks（AI 辅助）
- **AI 素材生成**：DeepWorks Image Gen（生成 V3 原创背景图）
