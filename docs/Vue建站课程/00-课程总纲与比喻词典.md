# Vue 建站入门：从零开始（小白·比喻版）

- **日期**：2026-09-16
- **读者**：假设是刚接触网页开发、只会一点 Python 的大一学生
- **风格**：全文不用「组件树、响应式、依赖注入」这类行业黑话打头，一律先用生活比喻讲通，再点出专业名词
- **目标**：读完能用自己的话回答——①我做的网站到底是什么；②每个文件夹是干嘛的；③为什么改一处、网站就变
- **参考**：本课程的结构参考了《机器学习入门：从零开始（小白·比喻版）》，做法是「每章一个比喻 + 章末一句话总结」

## 一、核心比喻：你的网站 = 一家餐厅

整个课程只用这一组比喻贯穿。**先记住这张表，后面每一章都回来查它。**

| 餐厅里的东西 | 网站里的东西 | 专业名词 | 你项目里的位置 |
|---|---|---|---|
| 菜（写了什么） | 内容 | 数据 | `src/data/site.js` |
| 装修配色（长什么样） | 外观 | 样式 CSS | `src/style.css` |
| 服务员（会动、会应） | 交互行为 | 脚本 JS | `.vue` 文件里的代码 |
| 一个个功能房间 | 页面 | 页面组件 | `src/views/` |
| 随处可搬的柜子 | 可复用小零件 | 通用组件 | `src/components/` |
| 楼层指示牌 | 网址跳转 | 路由 Router | `src/router/index.js` |
| 电子菜单屏 | 会自己更新的界面 | 响应式 | Vue 的核心能力 |
| 仓库（原料原样取出） | 静态素材 | 静态资源 | `public/` |
| 后厨车间（加工原料） | 处理过的代码 | 源码 | `src/` |
| 打包好的外卖盒 | 上线成品 | 构建产物 | `dist/` |
| 店面地址 | 网址 | 部署 | GitHub Pages |

## 三、给你的学习心法

1. **不要背名词**。英文文件名（`App.vue`、`vite.config.js`）只是「门牌号」，先知道门里是什么功能，名字自然记住。
2. **每章末尾的「一句话总结」要能自己复述出来**。复述不出来就是没懂，回头再看比喻。
3. **善用你已有的能力**。你会 Python、会量化那套「特征→模型→回测」的流程，这套「拆分→组装→验证」的思路在网页开发里一模一样。
4. **卡住就用比喻问我**。比如「`props` 是柜子上的标签吗？」——这种问法非常好，说明你在用旧知识挂新知识。
