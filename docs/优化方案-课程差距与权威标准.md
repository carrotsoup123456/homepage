## 三、网上查到的"好网站"权威标准

> 只取三家公认权威，都能直接对照到你的代码。

### 3.1 Google **Core Web Vitals**（核心网页指标）— 衡量"快不快、稳不稳"
来源：`https://web.dev/articles/vitals`、`https://web.dev/articles/defining-core-web-vitals-thresholds`

三个指标，判定按真实用户第 **75 百分位**：

| 指标 | 含义 | 好 | 需改进 | 差 |
|---|---|---|---|---|
| **LCP** Largest Contentful Paint | 主内容多久出现（加载感） | ≤ 2.5 s | 2.5–4.0 s | > 4.0 s |
| **INP** Interaction to Next Paint | 点一下多久有反应（流畅感） | ≤ 200 ms | 200–500 ms | > 500 ms |
| **CLS** Cumulative Layout Shift | 内容乱跳程度（稳定感） | ≤ 0.1 | 0.1–0.25 | > 0.25 |

**对你的指向**：CLS 是唯一有真实风险的一项——图片没写 `width/height`；LCP 受首屏大图（森林/头像）影响。

### 3.2 W3C **WCAG 2.2**（Web 内容可访问性指南）— 全世界公认的"合格线"
来源：`https://www.w3.org/WAI/standards-guidelines/wcag/`、`.../wcag/glance/`（已是 ISO/IEC 40500 国际标准）

四大原则 **POUR**：**可感知** Perceivable / **可操作** Operable / **可理解** Understandable / **健壮** Robust。

与你直接相关的条目：

| 条目 | 要求 | 你的状态 |
|---|---|---|
| 2.4.1 Bypass Blocks (A) | 提供"跳到主内容" | ❌ 无 |
| 2.4.7 Focus Visible (AA) | 键盘焦点必须看得见 | ❌ 无 `:focus-visible` |
| 2.4.2 Page Titled (A) | 每页要有自己的标题 | ❌ 全站同标题 |
| 1.1.1 Non-text Content (A) | 图片要有替代文字 | ✅ 7 张图都有 `alt` |
| 2.3.3 Animation from Interactions (AAA) | 动画可关闭 | ✅ 已做 `prefers-reduced-motion` |
| 1.4.3 Contrast (AA) | 正文对比度 ≥ 4.5:1 | ⚠️ 待实测（浅色主题的绿/石板蓝在小字上） |

### 3.3 NN/g **十大可用性启发式**（1994 提出，至今是行业事实标准）
来源：`https://www.nngroup.com/articles/ten-usability-heuristics/`

| # | 原则 | 一句话 | 你的状态 |
|---|---|---|---|
| 1 | 系统状态可见 | 让用户随时知道"我在哪、刚做了什么" | ⚠️ 导航无"当前页"标记、切页无标题变化 |
| 2 | 贴合真实世界 | 用用户的语言，不用内部黑话 | ✅ 做得好 |
| 3 | 用户控制与自由 | 随时能退出/撤销 | ✅ 有返回顶部、详情页可关闭 |
| 4 | 一致性与标准 | 同类东西长得一样、位置一样 | ✅ 做得好 |
| 5 | 错误预防 | 最好别让错误发生 | ⚠️ 表单可加校验 |
| 6 | 识别优于回忆 | 选项摆在眼前，别让人背 | ✅ 导航常驻 |
| 7 | 灵活与高效 | 给熟手快捷方式 | ⚠️ 缺键盘快捷操作 |
| 8 | 审美与极简 | 别放无关信息 | ✅ 做得好 |
| 9 | 帮用户识别/诊断/恢复错误 | 说人话 + 给出路 | ❌ 无 404 页 |
| 10 | 帮助与文档 | 需要时能查到帮助 | ⚠️ README 未写 |
